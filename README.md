# 天国スタジオ（Heaven Studio 日本語版）

[Heaven Studio](https://github.com/RHeavenStudio/HeavenStudio) を日本語にした非公式版です。
画面の文字・ミニゲーム名・同梱レベルが日本語になり、ミニゲームの声や画面の文字画像も日本語版『リズム天国』シリーズのものに置き換えています。

- ダウンロード: [Releases](../../releases)（Mac・Windows・Linux）
- 仕組みと翻訳ファイルの場所: [LOCALIZATION.md](LOCALIZATION.md)
- 日本語化した声・画像の一覧: [Japanese_Voice_Checklist.md](Japanese_Voice_Checklist.md)・[Japanese_Image_Checklist.md](Japanese_Image_Checklist.md)

### 起動のしかた
- **Mac**: zip を展開して「天国スタジオ.app」をアプリケーションに入れます。署名していないので、初回は右クリック →「開く」で起動してください。
- **Windows**: zip を展開して `天国スタジオ.exe` を起動します（「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」）。
- **Linux**: zip を展開して `天国スタジオ.x86_64` に実行権限を付けて起動します（`chmod +x 天国スタジオ.x86_64`）。

本家 Heaven Studio と同じパソコンに入れても、設定やライブラリは混ざりません。

## Self-Building

Heaven Studio (Bobby) is made in [Unity 2022.3.41](https://unity.com/releases/editor/whats-new/2022.3.41),
and programmed with [Visual Studio Code](https://code.visualstudio.com/).

Build Instructions: [BUILD.md](https://github.com/megaminerjenny/HeavenStudio/blob/master/BUILD.md) (or the more maintained [documentation page](https://rheavenstudio.github.io/docs-contributing/setup/introduction))
